# Mål

Gør Agent Mission Control til det bedste offentlige repo i klassen portable coding-agent skill: mindst ærlig kerne, klar install, verificerbar leverance.

## Succeskriterier

- En GitHub-besøgende forstår på forsiden hvad AMC er, hvad den ikke er, og hvordan man installerer den.
- GitHub About matcher produktet: portable skill, flere hosts, ingen ekstra server.
- Brugervejen er install → første opgave → rigtigt arbejde. Versionsarkæologi ligger i evidence, ikke på forsiden.
- `docs/` har ét kort. `docs/field-state.md` er det aktuelle evidenskort.
- Engineering-kontrakter forbliver grønne. Ingen homemade subject-farm. Ingen påstand om at AMC er billigere, hurtigere eller bedre uden ekstern evidens eller brugstelemetri.

## Begrænsninger

- Portable Markdown-skill. Ikke runtime, daemon, framework eller desktop-OS.
- Ingen merge, release, global install eller host-config uden konkret mandat i den aktuelle session.
- Stærk lead + billigere workers er valgfri og cost-aware, ikke identitet.
- Sandhed → Proof → UX → Beta.

## Uden for scope

- Stjerneantal eller at slå Superpowers på popularitet.
- SWE-bench- eller prissammenligning som produktbevis.
- At kopiere andre orchestrator-produkter som afhængigheder.
