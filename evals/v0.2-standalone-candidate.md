## Actual product

One canonical `SKILL.md` selects the smallest useful graph. Lead triage keeps
clear work direct; a cheap scout is conditional on useful uncertainty. Conditional
references own context/capability routing, measured selection, review, recovery,
resources and separate learning. There is no daemon, DAG engine, second task
store, provider layer or mandatory companion installation. Skill and plugin
are generated from the same source.

New workers receive fresh task-specific context packs. Necessary dependency
outputs travel through the lead, not entire sibling conversations. Research gets
its question/sources, implementation gets interfaces/findings, and review gets
requirements/current artifacts/evidence without the implementer's case for PASS.
Shared host instructions/catalog are still present; fresh history is not complete
prompt isolation. All ten new agents in this iteration used `fork_turns=none`.
