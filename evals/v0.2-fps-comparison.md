# One Sol direct-versus-AMC development comparison

**Both tasks PASS; retain the AMC incumbent. No cost advantage established.**

Two Sol/medium sessions repaired identical anonymous JSON fixtures. The direct
arm used ordinary single-agent work. The AMC arm explicitly read a frozen AMC
snapshot and selected direct work too, with no child agent. The responsible
controller independently reran both checks and made no source repairs.

| Observed measure | Sol direct | Sol with AMC |
| --- | ---: | ---: |
| Fixed outcomes | 18/18 | 18/18 |
| Additional agents | 0 | 0 |
| Native session seconds | 130.345 | 145.801 |
| Input tokens | 418,329 | 511,658 |
| Cached input (subset) | 385,792 | 501,760 |
| Noncached input | 32,537 | 9,898 |
| Output tokens | 3,922 | 4,825 |
| Tool calls | 9 | 11 |

Both identified the quoted reviewer claim as false. `TryGetInt32` required a
number-kind guard; both repairs also handle malformed root/status input. All
non-source fixture bytes and frozen evaluator/runtime hashes stayed unchanged.
Neither outcome was replaced by a retry. Both stayed below the monitored
180-second deadline and 600000 subject-input stop threshold.

The AMC body fragment was observed in its native tool output and not in the
direct arm. First calls had 39,565 and 39,638 input tokens. Both traces showed
61,715 developer-message characters and 15,544 user-message characters at visible
session initialization, with shared-home and skill-catalog markers. Those are
partial visible character counts, not a complete token decomposition of the
host/tool prompt. Fresh history did not imply a tiny initial input.

## Interpretation

The intended cheap route was exercised: explicit AMC did not manufacture a team
for a small task. It did not improve the functional result in this pair. AMC
used more total input, output and time, but less noncached input. Direct ran
first and shared cache state was not counterbalanced; no prices were measured.
Do not label either arm cheaper or generally better on this evidence.

This comparison found no attributable instruction defect that warrants changing
AMC. Existing direct-routing and verification guidance is retained. The separate
encoding fixture passed deterministic positive/negative controls and was not
given to these subjects. A changed-rule test on it was therefore not triggered.
No live rule, global configuration or frozen historical score changed.

## Accounting and test tooling

[Machine-readable results](results/2026-09-13-fps-comparison.json) include each
subject, the controller windows, and a whole-request snapshot covering the
controller, fixture builder, independent verifier and both Sol subjects. Failed
or missing records are not silently zero. All five expected sessions were found.
Snapshots stop at each last observed counter; unflushed work, later report
writing and the final response are excluded. This is not a billing statement.
Controller setup/monitoring/documentation dominates much of this experiment and
must not be hidden when describing cost. Window totals include different
controller activities and are not a clean end-to-end cost comparison.

Before freezing, review found a bug in the new evaluator: it initially derived
expected result keys from actual output, allowing an empty object to pass. Fixed
18-case keys and an empty-output negative control removed that false PASS before
any scored subject ran. Usage controls cover resets, window baselines, missing
counters, descendants, interrupted attempts, incomplete writes and transcript
exclusion. Candidate C# is trusted unsandboxed code, not a security sandbox.

[Run the two public replays](fps-replays.md) with one command. Routine regression
checks now run without model calls; rerunning agent comparisons is separate work.
The local structural validator, 27 negative controls, eleven fixture-preparation
cases, thirteen package tests and 117 preservation cases also pass. CI wiring
uses the official [setup-dotnet action](https://github.com/actions/setup-dotnet/tree/v4)
for .NET 8; remote CI has not run. The new cases are development data, not held-out
qualification or evidence that v0.2 replaces v0.1.
