## What this tests about AMC

- **Bounded delegation worked in these tasks.** Native metadata confirms Terra,
  Sol and Luna with the requested efforts. Fresh packets kept the handoff scoped;
  they did not remove shared host rules, skills, tools or filesystem access.
- **Independent review was insufficient by itself.** Luna asserted a false parser
  behavior. The responsible lead had to challenge it and require executable proof.
  This supports retaining the existing lead-verification rule; it does not show
  that a new rule, more reviewers or a stronger model would improve outcomes.
- **The graph adapted to evidence.** An audit result led to a tiny encoding repair;
  a failed review led to a focused regression and re-review. No always-scout
  comparison, automatic trigger test or AVO improvement experiment was performed.
- **Mechanical proof was useful.** Exact before/after bytes, parser execution,
  failed-input checks and tests detected faults that prose approval missed.

These were hosted, controller-assisted runs. Astra contributed materially, and
other shared instructions were active. Neither an Astra-free workflow nor AMC's
causal advantage over ordinary competent development was established.

First calls carried **37,620-39,714 input tokens** despite fresh conversation
packets. This demonstrates that `fork_turns=none` is not a small-total-context
guarantee. It does not identify which host component caused the input size.
Counters are cumulative usage, not unique context length or money. Controller
usage, unflushed future usage and billing are excluded; cached input has different
accounting and must not be added twice. There is no matched cost baseline.

Correction: the initial Sol attempt had been described as not initialized. Native
metadata shows **17 tool calls and nonzero usage**, with no final result. It is an
interrupted attempt that consumed resources, not zero-cost startup or a completed
Sol result. Earlier snapshots undercounted later Terra/Luna follow-ups; the JSON
report retains final observed counters and timestamps.

## Reuse as tests

The JSON report defines two replay contracts from the observed failures and one
matched cost-control contract. Existing application tests and private, hashed
before snapshots provide the original executable evidence. **A public standalone
fixture has not been extracted, and the new matched replays have not run.** These
cases are now development data; they must not be called held-out tests.

The next useful measurement is one matched direct-versus-AMC task with the same
lead model, inputs and checks, complete controller/child accounting, and failures
retained. A single pair would still be diagnostic. Do not broaden the model matrix
or claim learning gains from repairing the case that supplied the lesson.

No governing skill, global configuration, runtime package or frozen evaluator was
changed in these runs. Application source, raw sessions and private paths remain
outside this sanitized report. The application changes are local and uncommitted;
physical install/update and Boost/restore release acceptance remain unverified.
