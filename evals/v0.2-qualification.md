## Architecture and decision

Retain the original a04 selective runtime: a short SKILL.md with conditional
verification, recovery, delegation and optimization references. The attempted thin
routing to installed Context Diamond and AVO was rejected and restored byte for
byte. No daemon, dependency, mandatory team or online learning loop was added.
Offline learning remains separate from runtime authority. Context Diamond owns
specialized delegation; AVO owns measured optimization. Shared instructions and
companion mechanisms were audited, including potential duplicated routing authority.
The experiments do not establish that either composition is excellent for difficult,
long-running engineering; extra framework instructions have not earned that claim.

## Retained fixes and verification

aliases and reserved device names before writes; use lexists so dangling runtime
roots reach symlink/reparse rejection instead of being silently omitted.
The standard library handles device names, with a Python 3.11 fallback. Existing
Git isolation and link protections remain intact. Timestamp determinism is deferred:
identical trees with different commit timestamps were not established as corruption.

Root executed the 11 tripled fixture preparations on Python 3.11 and 3.14,
25 negative validator controls and 12 package tests: PASS. The new dangling-link
regression fails against the original helper. Independent final diff review found
no material regression. The 3.11 fallback does not validate every wildcard/control
character rejected by newer ntpath; that pre-existing limitation is outside this fix.
Final archive/scan hashes and Git state are in the external delivery proof.
