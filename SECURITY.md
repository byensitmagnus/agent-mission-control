# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing credentials, private prompts, customer data, or
details that would make an active vulnerability easier to exploit.

Include the affected instruction or workflow, the realistic impact, and the
smallest reproduction you can safely share. You should receive an initial
response within seven days.

## Scope

This repository contains agent instructions, not an execution service. Reports
about authority escalation, unsafe secret handling, destructive defaults,
verification bypass, or cross-worktree contamination are in scope.
